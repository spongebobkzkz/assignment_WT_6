3. Detective Deduction: Case 20 (The Thief Solution)

The mysterious thief was identified by chaining 5 strict forensic constraints simultaneously within a single jQuery traversal filter:

  1. Clue 1: Floor Location: Must be downstairs → $('#floor-1 .guest') limits the pool to the Living Room and Kitchen.
  2. Clue 2: Arrival Window: Arrived between 21:00 and 21:30 → data-arrival >= '21:00' && data-arrival <= '21:30'. In this window on Floor 1: Arman (21:20), Zarina (21:10), Aigul (21:05), Beksultan (21:30).
  3. Clue 3: Cookie Crumbs: Left crumbs → .has('.item:contains("🍪")'). Filters down to Arman, Zarina, Beksultan.
  4. Clue 4: No Drink: Has NO cup → .has('.item:contains("🥤")').length === 0. Arman holds a drink (🥤), eliminating him. Only Zarina and Beksultan remain.
  5. Clue 5: Neighboring Student: Stood right next to an AITU student → .prev('[data-university="AITU"]').length > 0 || .next('[data-university="AITU"]').length > 0. In Living Room, Zarina stands adjacent to Daniel (AITU) and Natasha. In Kitchen, Beksultan stands next to Miras (KBTU). Therefore, Zarina is definitively the culprit!

4. Task 2: The Party in Motion (Effects & Animations)

Task 2 introduces 4 jQuery-powered motion effects without using any CSS transition or animation rules:

Effect 1: Spotlight on Demand

When a case is executed or a spotlight filter is toggled, non-matching guests are smoothly dimmed using jQuery: $('.guest').not($found).stop(true, false).fadeTo(300, 0.2); while active candidates retain opacity: 1 with jump animations. Clicking "Clear Spotlight" restores all elements with $('.guest').stop(true, false).fadeTo(200, 1.0);.

Figure 4: Task 2 Spotlight dimming background guests to 20% opacity while highlighting targets.

Effect 2: Zoom Guest Card Modal

Clicking any guest avatar captures its dynamic viewport coordinates using $avatar.offset(). A modal card is created at those exact coordinates, matching the avatar's initial dimensions. It then smoothly animates to the center of the screen via jQuery: $modal.animate({ top: destTop, left: destLeft, width: 340, height: 420 }, 400); alongside a black overlay fade-in. Closing the modal (ESC, overlay click, or close button) reverses this animation back into the avatar's original slot and safely removes the modal from the DOM.

Figure 5: Zoomed guest card modal showing detailed profile, items, and room transfer buttons.

Effect 3: Fly to New Room

Inside the zoomed guest card modal, transfer buttons allow relocating any guest to another room (e.g. Living Room → Balcony). jQuery creates a floating clone at the source position, calculates the destination room's target offset, animates the clone across the screen in 500ms, appends the actual guest element into the target room's .guest-list, updates internal room arrays, and highlights the guest upon arrival.

Effect 4: Room Arrival Time Sorting

Each room header has a "Sort by Time" button. When triggered, guests in that room are sorted chronologically according to their data-arrival attribute (e.g., 20:30 → 21:05 → 21:10). jQuery smoothly slides elements into their newly ordered indices using sequential positional animations, ensuring seamless visual feedback.

5. Technical Conclusion & Best Practices Learned

  • Declarative Traversals: Using single jQuery chains (.has(), .filter(), .closest(), .siblings()) provides concise, expressive DOM queries that eliminate nested imperative loops and temporary state arrays.
  • Animation Queue Management: Calling .stop(true, false) before new animations prevents queue congestion when users click repeatedly or rapidly switch detective filters.
  • DOM & Data Consistency: State changes resulting from moving guests between rooms are synchronized both in the DOM tree and the underlying data structures, maintaining architectural integrity.
  • Pure JavaScript/jQuery Animation Engine: Building motion solely with jQuery's mathematical interpolation engine without relying on CSS transitions guarantees precise callback handling and complete cross-browser synchronization.
